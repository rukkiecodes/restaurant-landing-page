# Ember & Oak - Restaurant Landing Page

Reference solution for the HTML & CSS assignment: a responsive one-page restaurant website built with no JavaScript.

## Features
- Sticky nav with anchor links and a CSS-only hamburger menu (checkbox hack)
- Hero, menu (CSS Grid), about (two-column), gallery (hover zoom), reservation form, footer
- CSS variables, 2 media queries (tablet and mobile), transitions and a fade-in animation
- Semantic HTML, alt text and labelled form fields
- Stretch goals: smooth scrolling, `prefers-color-scheme` dark mode, reduced-motion support

## Run locally
Open `index.html` in a browser.
